# Glossary / Słowniczek (PL ↔ EN)

| Polski | English | Plain-language meaning / Po ludzku |
|---|---|---|
| szerokość rynku | market breadth | ile spółek uczestniczy w ruchu rynku / how many stocks take part in the move |
| średnia krocząca (SMA 200) | moving average (200-session SMA) | średni kurs z ostatnich 200 sesji (~10 miesięcy); kurs powyżej = długoterminowy trend wzrostowy |
| linia szybka / wolna | fast / slow line | wygładzony odsetek spółek nad SMA200 — krótkoterminowo (EMA 8) i długoterminowo (EMA 100) |
| spółki rosnące / spadające | advancers / decliners | spółki, które zamknęły sesję wyżej / niżej niż poprzednio |
| linia A/D | advance-decline line | skumulowana suma (rosnące − spadające) |
| oscylator McClellana | McClellan oscillator | tempo przewagi wzrostów nad spadkami; > 0 = przewaga wzrostów |
| nowe maksima / minima | new highs / lows | spółki na najwyższym / najniższym poziomie od ~roku |
| dywergencja | divergence | indeks idzie w jedną stronę, a większość spółek w drugą |
| ekspozycja na akcje | equity exposure | jaka część pieniędzy przeznaczonych na giełdę jest w akcjach (reszta: gotówka, obligacje) |
| płynność / obrót | liquidity / turnover | ile pieniędzy dziennie przechodzi przez akcje spółki |
| WIG20 / mWIG40 / sWIG80 | large / mid / small caps | 20 największych, 40 średnich, 80 mniejszych spółek GPW |
| sesja | trading session | dzień notowań (8:30-17:05 w systemie WATS) |
| groszówka | penny stock | akcja notowana poniżej 1 zł |
| korekta o split | split adjustment | przeliczenie historycznych cen po podziale akcji, żeby wykres był ciągły |

Tone guide for beginners: explain one concept per sentence, give a concrete
number from the report, avoid jargon without a translation in brackets.
